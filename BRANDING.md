# GoreeCloud Firefox Add-ons Branding

Branding authority: `GoreeCloud/branding-assets`.

Firefox add-on, extension, theme, plugin, and project icons, logos, badges, store artwork, promotional graphics, and shared GoreeCloud identity assets must be created and approved in the unified branding repository before being synchronized into this collection. Existing local artwork is a consumer derivative only and must not become an independent branding authority.

Branding does not establish functionality, privacy/security behavior, or release claims.

## Advanced Tab Manager packaged identity

Canonical asset: `GoreeCloud/branding-assets/products/advanced-tab-manager/app-icon.svg`  
Canonical Git blob: `2c1865ee3809ae91c3bcb42d2d39275668651ab7`  
Firefox consumer derivative: `extensions/advanced-tab-manager/icons/advanced-tab-manager.svg`

The Firefox derivative must remain byte-identical to the approved canonical SVG unless the branding authority changes first. Firefox manifest `icons` and `action.default_icon` must resolve to this derivative so Add-ons Manager and toolbar surfaces do not fall back to a generic extension placeholder.
