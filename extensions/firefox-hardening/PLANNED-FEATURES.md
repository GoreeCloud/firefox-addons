# Planned Features

These are planned or candidate directions and are not implemented or release-qualified unless later documented as such.

- Broader Firefox Enterprise Policy coverage with version-aware capability checks.
- Import/audit of an existing `policies.json` without silently applying it.
- Change preview and per-setting opt-out before profile application.
- Named custom profiles stored locally.
- Policy diff against the selected profile.
- Compatibility diagnostics for known high-breakage controls.
- Managed deployment templates for Linux, Windows, and macOS.
- Signed-release qualification, persistent-install/restart acceptance, and representative Firefox runtime testing.
- Accessibility and rendered UI acceptance across supported Firefox desktop platforms.
