Extended native hardening

Firefox Enterprise Policy

Firefox does not expose every browser preference to WebExtensions. The generated policies.json uses Firefox's native enterprise policy engine for additional startup-level controls. Review before deployment; policy files take effect after Firefox restarts.

Installation locations

Linux: /etc/firefox/policies/policies.json or the Firefox installation's distribution/policies.json.

Windows: place policies.json in a distribution directory beside the Firefox executable.

macOS: Firefox.app/Contents/Resources/distribution/policies.json.
