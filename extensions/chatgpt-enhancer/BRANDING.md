# GoreeCloud ChatGPT Enhancer — Branding

## Identity

**Product name:** GoreeCloud ChatGPT Enhancer  
**Short interface name:** ChatGPT Enhancer  
**Product family:** GoreeCloud Firefox add-ons

The product is a GoreeCloud extension for the ChatGPT web interface. It is not an OpenAI product and must not imply endorsement, ownership, or official affiliation beyond being an extension that operates on ChatGPT.

## Visual direction

The extension follows current GoreeCloud Glaze UI principles:

- strong information hierarchy;
- solid durable reading surfaces;
- restrained translucent treatment for transient command chrome;
- system typography;
- clear focus and state;
- rounded but functional geometry;
- accessibility fallbacks that remain usable without blur, transparency, or animation.

The source-candidate icon uses a GoreeCloud-styled gradient mark and a prominent “G” identity. It must not copy or imitate OpenAI's logo.

## Naming rules

Use **GoreeCloud ChatGPT Enhancer** in manifest, release, security, privacy, and repository identity contexts.

Use **ChatGPT Enhancer** where the GoreeCloud identity is already visually present and shorter UI text improves clarity.

Do not call the product “Official ChatGPT Enhancer,” “OpenAI ChatGPT Enhancer,” or otherwise imply that OpenAI publishes the extension.

## Lifecycle presentation

Packaged UI should use lifecycle-neutral product wording. Source-candidate, Release Candidate, signed, Stable, or other release state belongs in authoritative release documentation and repository metadata rather than misleading runtime branding.
