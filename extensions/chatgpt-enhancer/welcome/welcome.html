Welcome to ChatGPT Enhancer

A local-first layer for faster navigation, better reading, reusable prompts, and calmer long ChatGPT sessions.

START HERE

Three things to know

Open the command center

Press Alt + Shift + G on ChatGPT, or use the floating G button.

Return to your prompt

Press Alt + Shift + P to focus the ChatGPT composer immediately.

Make the workspace yours

Use Settings for width, text scale, focus/compact modes, prompt snippets, local backups, and optional draft recovery.

PRIVACY

Local by design

The extension does not use ChatGPT account APIs, read cookies or authentication tokens, send analytics, or run remote code. Draft recovery is off by default.

  • Runs only on chatgpt.com.
  • Uses Firefox extension storage for settings and user-saved snippets.
  • Conversation search and diagnostics stay in the page.
  • Exports happen only when you explicitly request them.
