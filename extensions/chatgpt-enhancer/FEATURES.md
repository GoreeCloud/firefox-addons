# GoreeCloud ChatGPT Enhancer — Features

## Productivity

- Keyboard command center.
- Direct prompt-composer focus shortcut.
- Search across currently loaded conversation messages.
- User-prompt outline with jump navigation.
- Previous/next user-prompt navigation.
- Jump to conversation top or bottom.
- Copy the last assistant response.
- Copy the loaded conversation as Markdown.
- Download the loaded conversation as Markdown.
- Local reusable prompt snippets with search in both the command center and Settings page.\n- Privacy-safe integration-health diagnostics containing selector availability and counts only.\n- Local settings/snippet JSON export and import with extension identity/schema validation and a 1 MiB import limit.

## Workspace presentation

- Wide conversation mode.
- Compact message spacing.
- Focus mode that hides side navigation.
- Long-code wrapping.
- Configurable conversation text scale.
- Configurable content width.
- Optional floating launcher.

## Continuity

- Opt-in local prompt-draft recovery.
- Per-conversation-path draft storage.
- Explicit restore rather than automatic insertion/submission.
- Bounded draft retention.
- One-action clearing of saved drafts.

## Accessibility and resilience

- Keyboard-accessible dialog controls.
- Visible focus states.
- Semantic labels, dialog role, status announcements, and list controls.
- Responsive popup, settings, and in-page command center.
- Reduced Motion fallback.
- Forced Colors fallback.
- Effects-free readable surfaces when blur is unavailable.
- Page-semantic selectors with conservative fallbacks.

## Privacy and security

- ChatGPT-only page scope.
- `storage` as the only explicit browser permission.
- No broad host access.
- No cookies, token access, request interception, telemetry, analytics, remote code, or extension-owned API calls.
- Private browsing disabled.
- Gecko data collection declared as none.
