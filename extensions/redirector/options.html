Redirect backup

Export rule definitions to a local JSON file. Import validates every rule first; rules that need a host permission you have not already granted are restored paused so Firefox can ask only when you enable them.

Privacy boundary

GoreeCloud Redirector does not inject scripts into websites, read page contents, use analytics, or contact an external service. Firefox evaluates redirect rules internally. Custom source-site access is requested only when you save a rule for that site.
